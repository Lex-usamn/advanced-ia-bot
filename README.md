# 🤖 Advanced IA Bot - Minecraft Plugin

Sistema avançado de bots IA para Minecraft com inteligência artificial, aprendizado contínuo e dashboard web completa.

## 🌟 Recursos

### 🧠 Inteligência Artificial
- Integração com API Gemini da Google
- Tomada de decisão autônoma baseada em contexto
- Aprendizado contínuo e adaptação

### 🎮 Funcionalidades dos Bots
- **Movimentação inteligente** - Exploração automática
- **Mineração** - Coleta de recursos valiosos
- **Construção** - Estruturas automáticas
- **Crafting** - Fabricação de itens
- **Combate** - Defesa contra mobs
- **Coleta** - Recursos do ambiente

### 📊 Sistema de Aprendizado
- **Inventário próprio** - Cada bot tem seu inventário
- **Sistema de níveis** - Progressão e evolução
- **Skills especializadas** - Mineração, construção, combate
- **Experiência acumulativa** - Ganho contínuo

### 🌐 Dashboard Web
- **Interface completa** - Monitoramento em tempo real
- **Autenticação segura** - Sistema de login
- **Gerenciamento** - Criar, remover, configurar bots
- **Estatísticas** - Níveis, experiência, status
